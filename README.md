# برنامهٔ آماده‌سازی و چاپ لیبل TSC — 80 × 60 mm

برنامه فایل‌های PDF و تصویر را به یک PDF چندصفحه‌ای تبدیل می‌کند؛ اندازهٔ هر صفحه دقیقاً ۸۰×۶۰ میلی‌متر است. هر صفحهٔ PDF یا هر تصویر یک لیبل جدا می‌شود. محتوای فایل بدون کشیدگی یا برش، وسط‌چین می‌شود.

## فایل‌های پشتیبانی‌شده

PDF، PNG، JPG/JPEG، BMP، TIFF، WEBP و GIF. فایل‌های Word و Excel را ابتدا به PDF تبدیل کنید.

## فرستادن پروژه به GitHub

برای اینکه GitHub بتواند فایل اجرایی ویندوز را بسازد، باید فایل workflow داخل پوشهٔ مخفی `.github/workflows` هم در مخزن قرار بگیرد. راه مطمئن، استفاده از GitHub Desktop است:

1. ZIP پروژه را استخراج کنید.
2. در GitHub یک مخزن جدید و خالی بسازید.
3. مخزن را با **GitHub Desktop** روی کامپیوتر Clone کنید.
4. تمام محتویات پوشهٔ `tsc_80x60_app` را، از جمله پوشهٔ مخفی `.github`، داخل پوشهٔ مخزن Cloneشده کپی کنید.
5. در GitHub Desktop تغییرها را Commit کنید و **Push origin** بزنید.
6. در صفحهٔ مخزن GitHub، تب **Actions** را باز کنید. اگر پیام فعال‌سازی workflow دیدید، آن را Enable کنید.

## دانلود فایل EXE ساخته‌شده

پس از Push به شاخهٔ `main` یا `master`:

1. در تب **Actions** اجرای **Build Windows app** را باز کنید.
2. صبر کنید وضعیت اجرا سبز و موفق شود.
3. پایین صفحه، در بخش **Artifacts**، فایل `TSC_Label_80x60-Windows` را دانلود کنید. ZIP دانلودشده شامل `TSC_Label_80x60.exe` است.

برای اجرای ساخت به‌صورت دستی: **Actions → Build Windows app → Run workflow**.

برای ساخت یک GitHub Release که فایل EXE به آن پیوست شود، یک tag با نامی مثل `v1.0.0` بسازید و push کنید:

```bash
git tag v1.0.0
git push origin v1.0.0
```

## اجرای مستقیم از سورس در ویندوز

1. Python 3.10 یا جدیدتر را نصب کنید.
2. `run.bat` را اجرا کنید. در اجرای اول، نصب PyMuPDF و Pillow به اینترنت نیاز دارد.
3. برنامه در مرورگر باز می‌شود؛ فایل‌ها را انتخاب کنید و PDF آمادهٔ چاپ بسازید.

## تنظیم چاپ

PDF نهایی با صفحه‌های دقیق ۸۰×۶۰ میلی‌متر ساخته می‌شود. در پنجرهٔ چاپ، درایور TSC را انتخاب کنید، مقیاس را روی **Actual size / 100%** بگذارید و از **Fit** استفاده نکنید. اندازهٔ Stock/Paper در درایور هم باید ۸۰×۶۰ میلی‌متر و نوع حسگر مطابق لیبل رول باشد.

برنامه روی همان کامپیوتر و به‌صورت محلی اجرا می‌شود. برای چاپ، PDF را باز کنید و پنجرهٔ معمول چاپ را بیاورید؛ برنامه بی‌صدا به پرینتر دستور نمی‌فرستد.
